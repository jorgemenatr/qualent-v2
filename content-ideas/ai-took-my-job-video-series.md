# AI Took My Job (The Boring Parts) - Video Series

Instagram video series about tasks I no longer do because AI handles them better.

## Format
- ~1 minute each
- Quick, punchy list format
- End each with "But here's what I still do myself..." for nuance

---

## Episode 1: Code I'll Never Write Again

**Hook:** "Code I used to write that I'll never write again..."

- Boilerplate/scaffolding
- Regex patterns
- Data transformation scripts
- Unit test generation
- CSS I can describe but don't want to write

**Closer:** What I still do myself - architecture decisions, debugging the weird stuff, knowing *what* to build

---

## Episode 2: Communication I've Outsourced

**Hook:** "Messages I let AI draft first..."

- First drafts of emails
- Summarizing meeting notes
- Professional-but-firm responses
- Documentation drafts
- Slack messages that need diplomacy

**Closer:** What I still do myself - actual conversations, relationship building, reading the room

---

## Episode 3: Research I Used to Do Manually

**Hook:** "Research that used to take hours..."

- Debugging error messages
- "How do I do X in Y framework"
- Comparing libraries/tools
- Understanding legacy code
- Reading docs so I don't have to

**Closer:** What I still do myself - evaluating if the answer is actually right, understanding the *why*

---

## Episode 4: The Thinking Work (Controversial?)

**Hook:** "This one might be controversial..."

- Brainstorming names/approaches
- Outlining blog posts or video scripts (meta!)
- Architecture decisions (as a sparring partner)
- Reviewing my own code
- Rubber duck debugging on steroids

**Closer:** What I still do myself - final decisions, taste, knowing when the AI is wrong

---

## Episode 5: The Stuff That Surprised Me

**Hook:** "Things I didn't expect AI to be good at..."

- [Fill in with personal examples]
- Where it still falls flat
- The new skills I've had to develop
- How my job has changed

**Closer:** The goal isn't to do less work—it's to do less *boring* work so I can focus on what actually matters.

---

## Notes
- Keep each video focused on ONE theme
- Show don't tell where possible (screen recordings?)
- Authentic > polished for Instagram
