Two directions for picklellama.studio

Each file is a working prototype, not a picture: real copy, real case-study numbers, a live English/Spanish switch, and a Home / Proof page toggle in the bottom-right corner. Open both on a phone as well as a desktop.

A — Worksheet

Quiet, precise, document-like. The hero is a live cost worksheet: three numbers you already know, and it computes what the problem costs you and what we would charge.

  • Archivo, tabular figures, left-aligned throughout
  • Green marks a computed figure; oxblood marks a loss
  • Proof is a ledger whose rows open in place
Open direction A

B — Yard

Loud, physical, built from industrial wayfinding — the visual language of the plants and warehouses your clients actually run. Full-bleed colour bands instead of cards.

  • Barlow Condensed signage type at poster scale
  • The guarantee set as one enormous painted 50%
  • Proof is a walk past bay doors, one band each
Open direction B

Both mockups use placeholder wordmarks for the client logos. On the live site those become the real SVGs — worth a pass either way, since the current row mixes a white-on-black block, a washed-out PNG and several very different lockup widths, so they read as seven unrelated objects rather than one row.
