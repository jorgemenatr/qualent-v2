# Campaign templates (mug-style)
Parody-packaging pieces derived from the five mug designs in `assets/campaigns/`: prescription label (1080²), nutrition facts (1080×1350), LinkedIn banner (1584×396). Rules: cream/white label on paper, 2–2.5px strong border, 24–32px radius, dashed inner rules, Oswald caps for label text, one red "TREATABLE"-style stamp max, wordmark always as SVG.

Isolated character PNGs: `assets/mascot/pose-standing.png`, `pose-labcoat.png`, `scene-farm.png`.
